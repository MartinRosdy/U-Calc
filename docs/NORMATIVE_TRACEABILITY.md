## Проверка параметра Б

HTML и Word-выгрузка LexUZ не содержат температурных ячеек таблицы 4, поэтому ранее бот
запрашивал значение у мастера. 14.10.2026 найден и визуально проверен официальный PDF на сайте
министерства. Пункт 14 задаёт метод, а таблица 4 даёт значения в колонке 10. Встроенные города
теперь переходят к выбору сценария без ручного подтверждения. Старые черновики с ручным override остаются
совместимыми; такое число хранится отдельно со статусом `user_supplied_unverified`.

## Правило для неподтверждённых значений

Новые расчёты из каталога материалов единообразно используют расчётную λБ
для условий эксплуатации Б. Паспортная λ точной марки и плотности имеет приоритет.
ППУ 0,028 Вт/(м·К) сохранён только для воспроизводимости старых записей: он не показывается
в UI и не принимается новым экспертным вводом; вместо него нужно ввести паспортную `λ=...`.

Значения со статусами `reference_unverified`, `legacy_reference_unverified`,
`typical_reference` и `normative_base_not_design` являются справочными. В клиентском результате появляется
предупреждение, а рабочий проект должен использовать паспортное λ/U или точную нормативную
строку с условиями эксплуатации.
